# 錯題自動收錄、純文字/圖形處理及 Checkpoint 規範

每當使用者在對話中上傳題目圖片或提及題目：
1. **純文字題目處理**：如果截圖本質為純文字題目（無實質幾何圖、函數圖、示意圖、圖表），**嚴格不放截圖**，`diagramUrl: ""` 留空，提取完整題幹文字與選項排版。
2. **圖表題目處理**：只有在題幹有實質圖形或選項為圖片時，才將圖片存至 `assets/questions/` 並設定 `diagramUrl`。若截圖中有作答痕跡或解答輔助線（如虛線、解析點號），必須主動清除還原為題目原始純淨圖形，避免劇透。選項若為圖片，需在選項文字中明確註明圖示與選項對照。
3. **學科分類與解析**：標記學科（`自然/生物`、`自然/理化`、`數學`、`國文`、`社會`）、段考範圍（`一段`）、易錯筆記與詳解。
4. **資料庫同步**：收錄至 `js/data.js` 的 `INITIAL_SEED_DATA`，升級 `STORAGE_KEY` 並保留 fallback 相容鏈。
5. **執行 Checkpoint 存檔**：完成每次收錄後，執行 Git commit 建立專案進度存檔點（Checkpoint），保留規範清晰的 commit message。
